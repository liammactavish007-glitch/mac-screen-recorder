## 维护时的安全测试

`--diagnostics` 只做空闲启动检查，不自动录屏。
`--hotkey-test` 会识别快捷键但拦截开始录制动作；测试后必须正常退出并以普通模式重新打开。

诊断模式会把权限、快捷键和保存目录写入系统临时目录的 `local-screen-recorder-diagnostics.json`，可能含个人路径，不应原样上传。

实际验收请明确选择录制内容，播放一段非敏感测试声音，可选开启麦克风说话，然后通过按钮停止保存；在播放器中检查画面和每个声源，并查看相邻 JSON 警告。声音数据包计数不等于声音可听清。
